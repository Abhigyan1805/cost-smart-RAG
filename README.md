costsmart-rag is a retrieval-augmented agent that doesn't send every query to the most expensive model. A lightweight router classifies each incoming question as a simple factual lookup or a complex, multi-step query, then dispatches it to either a small quantized model running locally (via Ollama) or a larger cloud LLM. An agent loop sits on top, checking answer confidence and deciding whether to re-retrieve, ask a clarifying question, or escalate to the bigger model. The project includes a built-in evaluation harness that tracks cost per query, latency, and accuracy against a hand-built eval set, so the cost/quality tradeoff is measured, not just claimed.
